# Noah Laurent — Portfolio créatif

Version statique du portfolio en HTML, CSS et JavaScript.

## Contenu

- `index.html` : structure et contenus de la page
- `portfolio.css` : typographie, mise en page responsive et effets visuels
- `portfolio.js` : navigation mobile, animations d’apparition et profondeur au survol
- `noah-portrait.webp` : portrait de démonstration
- `project-visuals.webp` : visuels des projets de démonstration

## Prévisualiser

Ouvrir `index.html` dans un navigateur. Pour une mise en ligne, téléverser les cinq fichiers à la racine d’un hébergement statique (par exemple Vercel ou Netlify). Aucun outil de compilation n’est nécessaire.

Les noms, projets, témoignages et coordonnées sont fictifs. L’adresse `bonjour@noah-laurent.example` est une adresse de démonstration à remplacer avant toute utilisation réelle. Les polices sont chargées depuis Google Fonts, avec des polices de secours si le service n’est pas disponible.
